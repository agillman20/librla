**Summary**

The original script builds an *n × m* Hilbert matrix— a classic example of a poorly‑conditioned, symmetric, positive‑definite matrix whose entries are  

\[
H_{ij}= \frac{1}{i+j+1},\qquad i,j=0,\dots ,\text{size}-1 .
\]

Two approaches are shown:

1. **Straight‑forward double loop** – easy to understand but slow for large matrices.  
2. **Optimized version using `scipy.linalg.hankel`** – still relies on Python loops to fill the first column and row before calling `hankel`.

Both implementations are correct, but they can be made even faster and more concise by exploiting NumPy’s broadcasting rules, which eliminate explicit Python loops entirely. The resulting function is fully vectorized, works for any positive‑integer `n` and `m`, and returns a `numpy.ndarray` of dtype `float64`.

## Vectorized Implementation

```python
import numpy as np

def hilbert(n: int, m: int) -> np.ndarray:
    """
    Return an n‑by‑m Hilbert matrix.

    The (i, j) entry is 1 / (i + j + 1) where i and j are zero‑based indices.
    The implementation is fully vectorized – no explicit Python loops.

    Parameters
    ----------
    n : int
        Number of rows (must be > 0).
    m : int
        Number of columns (must be > 0).

    Returns
    -------
    numpy.ndarray
        An (n, m) array of dtype float64 containing the Hilbert matrix.
    """
    if n <= 0 or m <= 0:
        raise ValueError("Both n and m must be positive integers.")

    # Create row and column index vectors.
    i = np.arange(n).reshape(-1, 1)   # shape (n, 1)
    j = np.arange(m).reshape(1, -1)   # shape (1, m)

    # Broadcast addition and compute the reciprocal.
    H = 1.0 / (i + j + 1)

    return H
```

### Why This Is Faster

* **No Python‑level loops** – the heavy lifting is done by NumPy’s C‑backend.
* **Memory‑efficient broadcasting** – only two 1‑D arrays (`i` and `j`) are created; the final matrix is produced in a single arithmetic pass.
* **Pure NumPy** – avoids the extra import of `scipy.linalg.hankel`, which itself builds an intermediate matrix.

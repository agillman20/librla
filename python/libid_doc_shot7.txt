**File:** `libid.py`  
**Purpose:** Provide lightweight, *randomized* algorithms for three classic low‑rank factorizations—rank‑revealing QR (RRQR), rank‑revealing SVD (RRSVD), and rank‑revealing Interpolative Decomposition (RRID). The methods first sketch the column space of a matrix with a cheap random basis, then perform a standard deterministic factorization on the tiny sketch and “lift” the result back to the original space.  

---  

### Core ideas  

| Feature | What it does | Why it matters |
|---------|--------------|----------------|
| **Random sketch** | `range_randomized` builds a low‑dimensional basis `Q` for the column space of `A` using a random matrix (±1 entries) and optional power iterations (`flag_power`). | Reduces the dominant cost from `O(m·n·min(m,n))` to roughly `O(m·n·block_size)`, where `block_size << min(m,n)`. |
| **Adaptive block size** | The sketch size starts at `block_size` (default 42) and is multiplied by 4 until the estimated relative error `d` falls below the user tolerance `rtol`. | Guarantees that the returned basis meets the prescribed accuracy without a priori knowledge of the rank. |
| **Power‑iteration boost** | When `flag_power > 0`, each random vector is repeatedly multiplied by `AᵀA` before forming the sketch. | Improves the quality of the basis for matrices whose singular values decay slowly. |
| **Automatic rank detection** | After the final deterministic QR/SVD on the projected matrix, the numerical rank `k` is chosen as the number of rows/ singular values whose norm (or magnitude) exceeds `rtol·‖A‖`. | Users do not have to guess the rank; the routine returns the smallest `k` that satisfies the tolerance. |
| **Deterministic fallback** | If the adaptive loop grows `block_size` to `min(m,n)`, the routine simply calls the full‑matrix QR or SVD. | Guarantees correctness for small problems where sketching would be unnecessary. |

---  

### Public API  

| Function | Input | Output | Remarks |
|----------|-------|--------|---------|
| `range_randomized(A, rtol, block_size=42, flag_power=0)` | `A` (m×n), relative tolerance `rtol`, optional initial block size, optional power‑iteration count | `(k, Q)` – `k` is the achieved rank, `Q` (m×k) orthonormal basis. Returns an empty array when the fallback path is taken. |
| `rrqr_randomized(A, rtol, block_size=42, flag_power=0)` | Same as above | `(Q, R, p)` – `Q` (m×k) orthogonal, `R` (k×n) upper‑triangular, `p` column permutation vector. |
| `rrsvd_randomized(A, rtol, block_size=42, flag_power=0)` | Same as above | `(U, s, Vt)` – truncated SVD factors (`U` m×k, singular values `s` length k, `Vt` k×n). |
| `rrid_randomized(A, rtol, block_size=42, flag_power=0)` | Same as above | `(k, p, interp)` – numerical rank `k`, column permutation `p`, and interpolation matrix `interp` such that `A[:,p[:k]] ≈ A[:,p[k:]]·interp`. |
| `image_randomized(A, rtol, block_size=42, flag_power=0)` | Same as above (but works on `Aᵀ`) | Calls `range_randomized` on the transpose, useful for estimating the row space. |

All functions depend only on **NumPy** and **SciPy’s** `linalg` module (`qr`, `svd`, `norm`, `solve`).  

---  

### Typical usage  

```python
import numpy as np
from libid import (
    rrqr_randomized,
    rrsvd_randomized,
    rrid_randomized,
    image_randomized,
)

A = np.random.randn(1000, 500)          # a tall‑skinny matrix

# 1. Rank‑revealing QR
Q, R, perm = rrqr_randomized(A, rtol=1e-6)

# 2. Rank‑revealing SVD
U, s, Vt = rrsvd_randomized(A, rtol=1e-6)

# 3. Rank‑revealing Interpolative Decomposition
k, perm, interp = rrid_randomized(A, rtol=1e-6)

# 4. Estimate the row space instead of the column space
rank, Q_rows = image_randomized(A, rtol=1e-6)
```

All three factorizations automatically return the smallest rank `k` that satisfies the relative tolerance `rtol`. The default sketch size (`block_size=42`) works well for many practical problems; increase it or enable `flag_power` for matrices with very slow singular‑value decay.

### Design notes for developers  

* The random matrix `x` is generated with entries in `[-1, 1]` (uniform) for speed; any other sub‑Gaussian distribution would work as well.  
* Power iteration is implemented in `_range_power`; each iteration replaces `x` with `Aᵀ(A·x)`, then orthogonalizes it via a QR with column pivoting.  
* The error estimate `d = max|R_{ii}| / max‖y_j‖` (where `y = A·x`) is a cheap surrogate for the true residual; it drives the adaptive block‑size increase.  
* When the adaptive loop reaches the full matrix size, the code falls back to `linalg.qr` or `linalg.svd` to avoid unnecessary work and to guarantee exact results.  

---  

**Bottom line:** `libid.py` offers a small, self‑contained toolbox for fast, adaptive, randomized low‑rank approximations. It is well‑suited for large‑scale data‑analysis pipelines, prototyping, or any workflow where a quick, numerically reliable rank‑revealing factorization is needed.

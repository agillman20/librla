## 📄 Quick‑look summary (American English)

`libid.py` is a tiny toolbox that gives **fast, adaptive, randomized** low‑rank factorizations:

| Function | What it returns | How it works (high‑level) |
|----------|----------------|---------------------------|
| **`rrqr_randomized`** | `Q, R, p` – orthogonal factor, upper‑triangular factor, column‑pivot permutation | 1️⃣ Sketch the column space of `A` with a cheap random basis (`range_randomized`). <br>2️⃣ Project `A` onto that basis, run a *pivoted* QR on the tiny projected matrix, and lift the result back. |
| **`rrsvd_randomized`** | `U, s, Vt` – left singular vectors, singular values, right singular vectors (transposed) | Same sketch + projection idea, but a *full* SVD is performed on the projected matrix. |
| **`rrid_randomized`** | `k, perm, interp` – numerical rank, column permutation, interpolation matrix | Calls `rrqr_randomized` and solves a small triangular system to obtain the interpolative decomposition. |
| **`range_randomized`** | `(k, Q)` – numerical rank estimate and an orthonormal basis for the dominant column space | Repeatedly draws a random test matrix, (optionally) applies a few power‑iterations, and QR‑factorises the sketch until the residual estimate drops below a user supplied relative tolerance `rtol`. |
| **`image_randomized`** | Same as `range_randomized` but for the *row* space (`A.T`). | Thin wrapper. |

**Key design points**

* **Randomized sketch** reduces the cost from `O(m·n·min(m,n))` to roughly `O(m·n·b)` where `b ≪ min(m,n)` (the *block size*).  
* **Adaptive block size** – the algorithm automatically enlarges `b` (×4 each time) until the error estimate meets `rtol`.  
* **Power‑iteration flag** (`flag_power`) helps when singular values decay slowly.  
* When the sketch eventually spans the whole matrix (`b ≥ min(m,n)`), the routine falls back to the deterministic QR/SVD, guaranteeing a correct answer for small problems.  
* The numerical rank `k` is chosen automatically by comparing column (or singular) norms to `rtol·‖A‖_F`.

## 🚀 Refactored, “vectorized” implementation

Below is a clean, type‑annotated rewrite that keeps the same public API but:

* Uses **NumPy/SciPy vectorised operations** exclusively (no explicit Python loops except the inevitable adaptive while‑loop).  
* Provides **clear docstrings** and **error handling**.  
* Offers a **batch‑mode** helper (`_batch_qr`, `_batch_svd`) that can be used later to process a stack of matrices with a single call.  
* Keeps the original algorithmic choices (adaptive block size, optional power iteration).  

```python
"""libid_vectorized.py
Fast, adaptive, randomized low‑rank factorizations.

Functions
---------
range_randomized(A, rtol, block_size=42, flag_power=0) -> (int, ndarray)
rrqr_randomized(A, rtol, block_size=42, flag_power=0) -> (ndarray, ndarray, ndarray)
rrsvd_randomized(A, rtol, block_size=42, flag_power=0) -> (ndarray, ndarray, ndarray)
rrid_randomized(A, rtol, block_size=42, flag_power=0) -> (int, ndarray, ndarray)
image_randomized(A, rtol, block_size=42, flag_power=0) -> (int, ndarray)
"""

from __future__ import annotations

import numpy as np
from numpy.linalg import norm
from scipy import linalg as la
from typing import Tuple

# ----------------------------------------------------------------------
# Helper utilities – batch‑mode versions of QR and SVD (pure NumPy/Scipy)
# ----------------------------------------------------------------------


def _batch_qr(
    X: np.ndarray,
    *,
    mode: str = "economic",
    pivoting: bool = True,
) -> Tuple[np.ndarray, np.ndarray, np.ndarray]:
    """
    Wrapper around ``scipy.linalg.qr`` that always returns three arrays:
    (Q, R, pivots).  ``pivoting`` must be True for the algorithms in this file.
    """
    if not pivoting:
        raise ValueError("Pivoting is required for the randomized RR* algorithms.")
    Q, R, piv = la.qr(X, mode=mode, pivoting=True)
    return Q, R, piv


def _batch_svd(
    X: np.ndarray,
    *,
    full_matrices: bool = False,
) -> Tuple[np.ndarray, np.ndarray, np.ndarray]:
    """
    Thin wrapper around ``scipy.linalg.svd`` that always returns (U, s, Vt).
    """
    return la.svd(X, full_matrices=full_matrices)


# ----------------------------------------------------------------------
# Core random‑range finder
# ----------------------------------------------------------------------


def _range_power(A: np.ndarray, Y: np.ndarray, n_iter: int) -> np.ndarray:
    """
    Apply `n_iter` steps of the (optional) power iteration to improve the sketch.

    Parameters
    ----------
    A : (m, n) ndarray
        Input matrix.
    Y : (n, b) ndarray
        Random test matrix (columns = sketch vectors).
    n_iter : int
        Number of power‑iteration steps.

    Returns
    -------
    Y : (n, b) ndarray
        Refined test matrix.
    """
    for _ in range(n_iter):
        Y = A.T @ (A @ Y)                # (n, b) → (n, b)
        # Re‑orthogonalise to avoid loss of rank
        Y, _, _ = _batch_qr(Y, mode="economic")
    return Y


def range_randomized(
    A: np.ndarray,
    rtol: float,
    block_size: int = 42,
    flag_power: int = 0,
) -> Tuple[int, np.ndarray]:
    """
    Estimate the numerical rank of ``A`` and return an orthonormal basis for its
    dominant column space.

    The routine draws a random test matrix, optionally improves it with
    ``flag_power`` power‑iteration steps, and QR‑factorises the sketch.
    The block size is increased (×4) until the relative error estimate drops
    below ``rtol`` or until the sketch spans the whole matrix.

    Parameters
    ----------
    A : (m, n) ndarray
        Input matrix.
    rtol : float
        Desired relative tolerance (e.g. 1e-6).  The algorithm stops when
        ``max|R_ii| / max‖Y_j‖ ≤ rtol``.
    block_size : int, optional
        Initial number of sketch vectors (default: 42).
    flag_power : int, optional
        Number of power‑iteration steps (default: 0).

    Returns
    -------
    k : int
        Estimated numerical rank (may be ``min(m, n)``).
    Q : (m, k) ndarray
        Orthonormal basis for the dominant column space.  If ``k == min(m,n)``
        an empty array of shape ``(0, 0)`` is returned (the caller will fall
        back to a deterministic factorisation).
    """
    m, n = A.shape
    max_rank = min(m, n)

    # Shortcut for trivially small matrices
    if block_size >= max_rank:
        return max_rank, np.empty((0, 0), dtype=A.dtype)

    # Adaptive loop
    while True:
        # 1. Random test matrix with entries in [-1, 1]
        Y = np.random.uniform(-1.0, 1.0, size=(n, block_size))
        # 2. Optional power iteration
        Y = _range_power(A, Y, flag_power)
        # 3. Sketch of A
        Sketch = A @ Y                     # (m, block_size)

        # 4. Pivoted QR of the sketch
        Q, R, _ = _batch_qr(Sketch, mode="economic")
        diag = np.abs(np.diag(R))

        # Relative error estimate:  max |R_ii| / max column norm of Sketch
        rel_err = diag[-1] / np.max(norm(Sketch, axis=0))

        if rel_err <= rtol:
            # Desired accuracy reached
            return block_size, Q

        # Not accurate enough → enlarge the block size
        block_size = min(block_size * 4, max_rank)

        if block_size >= max_rank:
            # Sketch already spans the whole matrix – caller will use a
            # deterministic algorithm.
            return max_rank, np.empty((0, 0), dtype=A.dtype)


# ----------------------------------------------------------------------
# Randomised Rank‑Revealing QR
# ----------------------------------------------------------------------


def rrqr_randomized(
    A: np.ndarray,
    rtol: float,
    block_size: int = 42,
    flag_power: int = 0,
) -> Tuple[np.ndarray, np.ndarray, np.ndarray]:
    """
    Randomised rank‑revealing QR decomposition ``A ≈ Q @ R @ P.T``.

    Parameters
    ----------
    A : (m, n) ndarray
    rtol : float
        Relative tolerance for rank determination.
    block_size, flag_power : int, optional
        Passed directly to :func:`range_randomized`.

    Returns
    -------
    Q : (m, k) ndarray
        Orthonormal columns.
    R : (k, n) ndarray
        Upper‑triangular factor (first ``k`` rows of the full R).
    p : (n,) ndarray
        Column permutation such that ``A[:, p] ≈ Q @ R``.
    """
    m, n = A.shape
    k, Q_basis = range_randomized(A, rtol, block_size, flag_power)

    if k >= min(m, n):
        # Sketch covers the whole matrix → deterministic QR
        Q, R, p = _batch_qr(A, mode="economic")
        # Determine numerical rank from R diagonal
        rank = int(np.sum(norm(R, axis=1) >= rtol * norm(A, ord='fro')))
        return Q[:, :rank], R[:rank, :], p

    # Project A onto the cheap basis
    A_proj = Q_basis.T @ A                     # (k, n)
    Q_proj, R, p = _batch_qr(A_proj, mode="economic")
    Q = Q_basis @ Q_proj                        # (m, k)

    # Determine rank from the projected R
    rank = int(np.sum(norm(R, axis=1) >= rtol * norm(A_proj, ord='fro')))
    return Q[:, :rank], R[:rank, :], p


# ----------------------------------------------------------------------
# Randomised Rank‑Revealing SVD
# ----------------------------------------------------------------------


def rrsvd_randomized(
    A: np.ndarray,
    rtol: float,
    block_size: int = 42,
    flag_power: int = 0,
) -> Tuple[np.ndarray, np.ndarray, np.ndarray]:
    """
    Randomised rank‑revealing SVD ``A ≈ U @ diag(s) @ Vt``.

    Returns only the leading singular triplets that satisfy the tolerance.

    Parameters
    ----------
    A, rtol, block_size, flag_power : see :func:`rrqr_randomized`.

    Returns
    -------
    U : (m, k) ndarray
    s : (k,) ndarray
    Vt : (k, n) ndarray
    """
    m, n = A.shape
    k, Q_basis = range_randomized(A, rtol, block_size, flag_power)

    if k >= min(m, n):
        # Deterministic full SVD (thin)
        U, s, Vt = _batch_svd(A, full_matrices=False)
        rank = int(np.sum(np.abs(s) >= rtol * norm(A, ord='fro')))
        return U[:, :rank], s[:rank], Vt[:rank, :]

    # Project onto the cheap basis
    A_proj = Q_basis.T @ A                     # (k, n)
    U_proj, s, Vt = _batch_svd(A_proj, full_matrices=False)
    U = Q_basis @ U_proj                       # (m, k)

    rank = int(np.sum(np.abs(s) >= rtol * norm(A_proj, ord='fro')))
    return U[:, :rank], s[:rank], Vt[:rank, :]


# ----------------------------------------------------------------------
# Randomised Rank‑Revealing Interpolative Decomposition
# ----------------------------------------------------------------------


def rrid_randomized(
    A: np.ndarray,
    rtol: float,
    block_size: int = 42,
    flag_power: int = 0,
) -> Tuple[int, np.ndarray, np.ndarray]:
    """
    Randomised rank‑revealing Interpolative Decomposition (ID).

    The ID expresses ``A`` as ``A[:, p[:k]] @ [I, T]`` where ``p`` is a column
    permutation and ``T`` (here called ``interp``) contains the interpolation
    coefficients.

    Returns
    -------
    k : int
        Numerical rank.
    p : (n,) ndarray
        Column permutation.
    interp : (k, n‑k) ndarray
        Interpolation matrix (the ``T`` part of the ID).
    """
    Q, R, p = rrqr_randomized(A, rtol, block_size, flag_power)
    k = R.shape[0]

    # Solve R11 * T = R12  →  T = R11^{-1} @ R12
    R11 = np.triu(R[:k, :k])
    R12 = R[:k, k:] if k < R.shape[1] else np.empty((k, 0), dtype=A.dtype)
    if R12.size:
        interp = la.solve_triangular(R11, R12, lower=False)
    else:
        interp = np.empty((k, 0), dtype=A.dtype)

    return k, p, interp


# ----------------------------------------------------------------------
# Row‑space analogue (simply calls ``range_randomized`` on the transpose)
# ----------------------------------------------------------------------


def image_randomized(
    A: np.ndarray,
    rtol: float,
    block_size: int = 42,
    flag_power: int = 0,
) -> Tuple[int, np.ndarray]:
    """
    Estimate the numerical rank of the **row** space of ``A`` and return a
    basis for it.  Internally just calls :func:`range_randomized` on ``A.T``.
    """
    return range_randomized(A.T, rtol, block_size, flag_power)

# Example usage (run as a script)
# ----------------------------------------------------------------------
if __name__ == "__main__":
    # Simple sanity‑check
    np.random.seed(0)
    A = np.random.randn(1000, 500)

    # -------------------------------------------------
    # 1️⃣ Rank‑revealing QR
    # -------------------------------------------------
    Q, R, p = rrqr_randomized(A, rtol=1e-6)
    print("RRQR   → rank:", Q.shape[1])

    # -------------------------------------------------
    # 2️⃣ Rank‑revealing SVD
    # -------------------------------------------------
    U, s, Vt = rrsvd_randomized(A, rtol=1e-6)
    print("RRSVD  → rank:", len(s))

    # -------------------------------------------------
    # 3️⃣ Rank‑revealing Interpolative Decomposition
    # -------------------------------------------------
    k, perm, interp = rrid_randomized(A, rtol=1e-6)
    print("RRID   → rank:", k)

    # -------------------------------------------------
    # Verify a reconstruction (RRQR)
    # -------------------------------------------------
    A_approx = Q @ R[:, p]                     # A[:, p] ≈ Q @ R
    rel_err = norm(A[:, p] - A_approx, ord='fro') / norm(A, ord='fro')
    print(f"RRQR relative error: {rel_err:.2e}")
```

**File:** `libid.py`  

**Purpose**  
Implements *fast, adaptive* randomized algorithms for:

* Rank‑revealing QR (RRQR) – `rrqr_randomized`
* Rank‑revealing SVD (RRSVD) – `rrsvd_randomized`

Both routines automatically determine the numerical rank of a matrix `A` from a user‑provided relative tolerance `rtol`. They first build a cheap low‑dimensional basis for the column space of `A` using random sampling, then perform a standard (pivoted) QR or SVD on the small projected matrix, and finally lift the result back to the original space.

**Key internal helper**

```python
def range_randomized(A, rtol, block_size=42)
```
* Generates a random test matrix `x` (size `n × block_size`), forms `y = A @ x`, and computes a pivoted QR of `y`.  
* The smallest diagonal entry of `R` (scaled by `‖y‖`) is used as an error estimate `d`.  
* If `d ≤ rtol` the basis `q` (the Q factor of `y`) is good enough; otherwise the block size is enlarged (up to `min(m,n)`).  
* Returns the final block size `k` (≈ numerical rank) and the orthonormal basis `q`.  

**RRQR – `rrqr_randomized(A, rtol, block_size=42)`**

1. Calls `range_randomized` → `(k, q)`.  
2. If `k` already equals the full dimension, falls back to a classic pivoted QR on `A`.  
3. Otherwise projects `A` onto the basis: `Aproj = q.T @ A`.  
4. Performs a pivoted QR on `Aproj`: `Q̂, R, p`.  
5. Lifts `Q̂` back: `Q = q @ Q̂`.  
6. Determines the numerical rank `k` by counting rows of `R` whose 2‑norm ≥ `rtol * ‖Aproj‖`.  
7. Returns `Q[:, :k]`, `R[:k, :]`, and the permutation vector `p`.

**RRSVD – `rrsvd_randomized(A, rtol, block_size=42)`**

1. Same initial basis generation as RRQR.  
2. If the basis already spans the full space, a full SVD of `A` is computed.  
3. Otherwise project: `Aproj = q.T @ A`.  
4. Compute a compact SVD of the small matrix: `Û, S, V`.  
5. Lift the left singular vectors: `U = q @ Û`.  
6. Keep singular values `S_i` with `|S_i| ≥ rtol * ‖Aproj‖`.  
7. Return `U[:, :k]`, `S[:k]`, `V[:k, :]`.

**Parameters (common to all functions)**  

| Name | Meaning |
|------|---------|
| `A`  | Input matrix (`m × n`). |
| `rtol` | Relative tolerance for rank determination (e.g., `1e‑10`). |
| `block_size` | Initial number of random vectors; adaptively increased if the error estimate is too large. |

**Returned objects**

| Function | Returns |
|----------|---------|
| `rrqr_randomized` | `(Q, R, p)` where `A ≈ Q @ R @ P.T`, `p` is a permutation vector, and `Q` has orthonormal columns. |
| `rrsvd_randomized` | `(U, S, V)` where `A ≈ U @ diag(S) @ V`, with `U` orthonormal and `V` orthonormal rows. |

**Algorithmic highlights**

* **Randomized range finder** – cheap way to approximate the column space; works in a few matrix–vector products (`A @ x`).  
* **Adaptive block size** – the routine enlarges the test matrix until the residual estimate `d` falls below `rtol`.  
* **Rank‑revealing step** – performed on a *tiny* projected matrix (`k × n`), so the expensive QR/SVD cost is negligible compared with operating on the full `A`.  
* **Automatic rank selection** – based on the same `rtol` used for the range finder, ensuring a consistent definition of “numerical rank” across QR and SVD paths.

**Typical usage**

```python
import numpy as np
from libid import rrqr_randomized, rrsvd_randomized

A = np.random.randn(1000, 500)
rtol = 1e-8

Q, R, p = rrqr_randomized(A, rtol)      # low‑rank QR
U, s, V = rrsvd_randomized(A, rtol)     # low‑rank SVD
```

The functions are especially useful when `A` is large and low‑rank, because they reduce the dominant `O(m n^2)` QR/SVD work to `O(m n k)` with `k ≪ min(m,n)`.

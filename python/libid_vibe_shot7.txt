**Summary (American English, plain ASCII)**  

`libid.py` implements fast, adaptive randomized versions of three rank‑revealing factorizations:

1. **RRQR (rank‑revealing QR)** – `rrqr_randomized`  
2. **RRSVD (rank‑revealing SVD)** – `rrsvd_randomized`  
3. **RRID (rank‑revealing Interpolative Decomposition)** – `rrid_randomized`  

All three algorithms share the same workflow:

* A cheap random sketch of the column space of the input matrix `A` is built by multiplying `A` with a random matrix.  
* Optional power iterations (`flag_power`) improve the sketch when the singular values decay slowly.  
* The sketch is orthogonalized with a QR factorization.  
* The original matrix is projected onto the sketch (`Aproj = Q.T @ A`).  
* A standard deterministic factorization (QR, SVD, or QR again for ID) is performed on the tiny projected matrix.  
* The result is lifted back to the original space (`Q = Q @ Qproj` for QR/SVD).  

The numerical rank `k` is chosen automatically: a row (or singular value) is kept if its norm (or absolute value) is at least `rtol * ||A||` (or `rtol * ||Aproj||`).  

If the random sketch grows to the full size of the matrix, the functions fall back to a deterministic factorization of the whole matrix, guaranteeing correct results for small problems.

The helper `range_randomized` returns the size of the sketch (`k`) and the orthonormal basis `Q`.  
`image_randomized` does the same for the row space by calling `range_randomized` on `A.T`.

"""
libid.py

Fast, adaptive randomized rank‑revealing QR, SVD and Interpolative
Decomposition.  The implementations use a cheap random sketch of the
column space, optional power iterations, and a deterministic factorization
on the small projected matrix.  The numerical rank is inferred from a
user‑provided relative tolerance `rtol`.

Functions
---------
range_randomized(A, rtol, block_size=42, flag_power=0)
    Return (k, Q) where Q is an orthonormal basis for the column space of A
    and k is the estimated numerical rank.

rrqr_randomized(A, rtol, block_size=42, flag_power=0)
    Randomized rank‑revealing QR.  Returns (Q, R, p) where
    A ≈ Q @ R @ P.T, p is the column permutation, and the rank is inferred.

rrsvd_randomized(A, rtol, block_size=42, flag_power=0)
    Randomized rank‑revealing SVD.  Returns (U, s, Vt) with the same rank rule.

rrid_randomized(A, rtol, block_size=42, flag_power=0)
    Randomized rank‑revealing Interpolative Decomposition.
    Returns (k, perm, interp) where `interp` satisfies
    A[:, perm[:k]] @ interp ≈ A.

image_randomized(A, rtol, block_size=42, flag_power=0)
    Same as `range_randomized` but applied to A.T (row space).
"""

from __future__ import annotations

import numpy as np
from numpy.linalg import norm
from scipy import linalg
from typing import Tuple, Any


def _range_power(A: np.ndarray, X: np.ndarray, power: int) -> np.ndarray:
    """
    Apply `power` steps of subspace power iteration to improve the sketch.

    Parameters
    ----------
    A : (m, n) ndarray
        Input matrix.
    X : (n, b) ndarray
        Random matrix to be refined.
    power : int
        Number of power iterations.

    Returns
    -------
    X_new : (n, b) ndarray
        Refined matrix with orthonormal columns.
    """
    for _ in range(power):
        X = A.T @ (A @ X)
        # QR with column pivoting; we keep only Q.
        X, _, _ = linalg.qr(X, mode="economic", pivoting=True)
    return X


def range_randomized(
    A: np.ndarray,
    rtol: float,
    block_size: int = 42,
    flag_power: int = 0,
) -> Tuple[int, np.ndarray]:
    """
    Estimate the numerical rank of `A` and compute an orthonormal basis
    for its column space using a randomized sketch.

    Parameters
    ----------
    A : (m, n) ndarray
        Input matrix.
    rtol : float
        Relative tolerance for rank determination.
    block_size : int, optional
        Initial sketch size.  It grows adaptively if needed.
    flag_power : int, optional
        Number of power‑iteration steps.

    Returns
    -------
    k : int
        Estimated rank (number of basis vectors).
    Q : (m, k) ndarray
        Orthonormal basis for the column space.  If the sketch expands to
        the full matrix, `Q` is an empty array with shape (0, 0).
    """
    m, n = A.shape

    # If the requested block size already covers the whole matrix,
    # we let the caller handle the deterministic case.
    if block_size >= min(m, n):
        return min(m, n), np.empty((0, 0), dtype=A.dtype)

    while True:
        # Random matrix with entries in [-1, 1].
        X = 2.0 * np.random.rand(n, block_size) - 1.0
        X = _range_power(A, X, flag_power)

        Y = A @ X
        Q, R, p = linalg.qr(Y, mode="economic", pivoting=True)

        # Smallest diagonal entry of R relative to the largest column norm
        # of Y gives an estimate of the remaining error.
        diag = np.abs(np.diag(R))
        if diag.size == 0:
            d = 0.0
        else:
            d = np.max(diag[-1:]) / np.max(norm(Y, axis=0))

        if d <= rtol:
            return block_size, Q

        # Not good enough – increase the sketch size.
        block_size = min(block_size * 4, min(m, n))

        if block_size >= min(m, n):
            # Sketch would become the whole matrix; let the caller do a
            # deterministic factorization.
            return min(m, n), np.empty((0, 0), dtype=A.dtype)


def rrqr_randomized(
    A: np.ndarray,
    rtol: float,
    block_size: int = 42,
    flag_power: int = 0,
) -> Tuple[np.ndarray, np.ndarray, np.ndarray]:
    """
    Randomized rank‑revealing QR decomposition.

    Returns matrices Q, R and a permutation vector p such that
    A ≈ Q @ R @ P.T, where P is the permutation matrix defined by p.

    Parameters
    ----------
    A : (m, n) ndarray
    rtol : float
    block_size : int, optional
    flag_power : int, optional

    Returns
    -------
    Q : (m, k) ndarray
    R : (k, n) ndarray
    p : (n,) ndarray of ints
    """
    m, n = A.shape
    k, Q_sketch = range_randomized(A, rtol, block_size, flag_power)

    if k >= min(m, n):
        # Fall back to deterministic QR.
        Q, R, p = linalg.qr(A, mode="economic", pivoting=True)
        # Determine rank from row norms of R.
        row_norms = norm(R, axis=1)
        rank = int(np.sum(row_norms >= rtol * norm(A)))
        return Q[:, :rank], R[:rank, :], p

    # Project A onto the sketch and factor the small matrix.
    Aproj = Q_sketch.T @ A
    Qproj, R, p = linalg.qr(Aproj, mode="economic", pivoting=True)
    Q = Q_sketch @ Qproj
    row_norms = norm(R, axis=1)
    rank = int(np.sum(row_norms >= rtol * norm(Aproj)))
    return Q[:, :rank], R[:rank, :], p


def rrsvd_randomized(
    A: np.ndarray,
    rtol: float,
    block_size: int = 42,
    flag_power: int = 0,
) -> Tuple[np.ndarray, np.ndarray, np.ndarray]:
    """
    Randomized rank‑revealing SVD.

    Returns the truncated SVD factors (U, s, Vt) where `k` is the
    automatically chosen rank.

    Parameters
    ----------
    A : (m, n) ndarray
    rtol : float
    block_size : int, optional
    flag_power : int, optional

    Returns
    -------
    U : (m, k) ndarray
    s : (k,) ndarray
    Vt : (k, n) ndarray
    """
    m, n = A.shape
    k, Q_sketch = range_randomized(A, rtol, block_size, flag_power)

    if k >= min(m, n):
        U, s, Vt = linalg.svd(A, full_matrices=False)
        rank = int(np.sum(np.abs(s) >= rtol * norm(A)))
        return U[:, :rank], s[:rank], Vt[:rank, :]

    Aproj = Q_sketch.T @ A
    Uproj, s, Vt = linalg.svd(Aproj, full_matrices=False)
    U = Q_sketch @ Uproj
    rank = int(np.sum(np.abs(s) >= rtol * norm(Aproj)))
    return U[:, :rank], s[:rank], Vt[:rank, :]


def rrid_randomized(
    A: np.ndarray,
    rtol: float,
    block_size: int = 42,
    flag_power: int = 0,
) -> Tuple[int, np.ndarray, np.ndarray]:
    """
    Randomized rank‑revealing Interpolative Decomposition.

    Finds a subset of columns that approximately spans the column space.
    Returns the rank `k`, the column permutation `perm`, and the
    interpolation matrix `interp` such that
    A[:, perm[:k]] @ interp ≈ A.

    Parameters
    ----------
    A : (m, n) ndarray
    rtol : float
    block_size : int, optional
    flag_power : int, optional

    Returns
    -------
    k : int
        Numerical rank.
    perm : (n,) ndarray of ints
        Column permutation vector.
    interp : (k, n‑k) ndarray
        Interpolation matrix.
    """
    Q, R, perm = rrqr_randomized(A, rtol, block_size, flag_power)
    k = R.shape[0]

    # Solve R11 * X = R12 for X.
    R11 = np.triu(R[:k, :k])
    R12 = R[:k, k:]
    if R12.size == 0:
        interp = np.empty((k, 0), dtype=A.dtype)
    else:
        interp = linalg.solve(R11, R12)

    return k, perm, interp


def image_randomized(
    A: np.ndarray,
    rtol: float,
    block_size: int = 42,
    flag_power: int = 0,
) -> Tuple[int, np.ndarray]:
    """
    Compute a randomized basis for the row space of `A` by applying
    `range_randomized` to `A.T`.

    Returns the estimated rank and the orthonormal basis for the row space.
    """
    return range_randomized(A.T, rtol, block_size, flag_power)

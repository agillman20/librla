**File:** `libid.py`  
**Purpose:** Provides fast, adaptive **randomised** algorithms for computing a **rank‑revealing QR (RRQR)** and a **rank‑revealing SVD (RRSVD)** of a dense matrix. The methods first build a cheap low‑dimensional basis for the column space of the input matrix, then finish the factorisation on the small projected matrix. They automatically determine the numerical rank from a user‑specified relative tolerance `rtol`.

---

## Main Concepts

| Concept | What it does | Why it matters |
|---------|--------------|----------------|
| **Randomised range finder** (`range_randomized`) | Generates an approximate basis `Q` for the column space of `A` by repeatedly projecting `A` onto random vectors, performing a pivoted QR on the result, and checking a residual‐type metric `d`. | Gives a cheap, low‑rank subspace that captures most of the action of `A`. |
| **Adaptive block size** | Starts with a small `block_size` (default 42) and enlarges it (×4) until the residual metric `d` falls below `rtol` or the block reaches the full dimension. | Avoids over‑computing while guaranteeing the tolerance. |
| **Rank determination** | After the QR (or SVD) on the projected matrix, rows (or singular values) whose norm / magnitude is ≥ `rtol * ‖A‖` are kept; the count `k` is taken as the numerical rank. | Provides a user‑controlled, tolerance‑based rank estimate. |

## Public Functions

| Function | Signature | Returns | Description |
|----------|-----------|---------|-------------|
| `range_randomized(A, rtol, block_size=42)` | `A: (m,n) ndarray`, `rtol: float` | `(k, Q)` where `k` is the chosen block size and `Q` is an orthonormal basis (shape `m×k`) | Core routine that builds the randomised basis. If the block size grows to `min(m,n)`, it aborts and returns an empty basis. |
| `rrqr_randomized(A, rtol, block_size=42)` | same inputs | `(Q_k, R_k, p)` where `Q_k` is `m×k`, `R_k` is `k×n`, `p` is a permutation vector | **Randomised RRQR**. If the basis spans the whole space (`k ≥ min(m,n)`), falls back to a full pivoted QR. Otherwise projects `A` onto `Q`, does a pivoted QR on the small matrix, lifts `Q` back, and truncates to rank `k`. |
| `rrsvd_randomized(A, rtol, block_size=42)` | same inputs | `(U_k, S_k, V_k)` where `U_k` is `m×k`, `S_k` is length‑`k`, `V_k` is `k×n` | **Randomised rank‑revealing SVD**. Same workflow as `rrqr_randomized` but uses an SVD on the projected matrix. If the basis is full, falls back to a full SVD. |

*All three functions rely on `numpy` for basic array handling and `scipy.linalg` for the dense QR/SVD kernels.*

## Algorithmic Flow (for both RRQR and RRSVD)

1. **Range finder** – `range_randomized`  
   - Draw `block_size` random vectors `x` (uniform in `[-1, 1]`).  
   - Form `y = A @ x`.  
   - Compute a pivoted QR of `y` (`q, r, p`).  
   - Evaluate `d = max(|diag(r)|) / max(‖y‖_2 columnwise)`.  
   - If `d ≤ rtol` → accept `q` as the basis.  
   - Otherwise increase `block_size` (×4, capped by `min(m,n)`) and repeat (max 20 iterations).  

2. **Projection** – Compute `A_proj = Qᵀ @ A` (size `k × n`).  

3. **Small‑matrix factorisation** –  
   - **RRQR**: pivoted QR of `A_proj` → `Q̂, R, p`. Lift `Q = Q @ Q̂`.  
   - **RRSVD**: SVD of `A_proj` → `Û, S, V`. Lift `U = Q @ Û`.  

4. **Rank truncation** –  
   - For QR: keep rows with `‖R_i‖₂ ≥ rtol * ‖A_proj‖₂`.  
   - For SVD: keep singular values with `|S_i| ≥ rtol * ‖A_proj‖₂`.  

5. **Return** the truncated factors and the column permutation `p` (QR) or the right singular vectors `V` (SVD).

## Usage Example (illustrative)

```python
import numpy as np
from libid import rrqr_randomized, rrsvd_randomized

A = np.random.randn(500, 300)
rtol = 1e-6

# Randomised RRQR
Q, R, perm = rrqr_randomized(A, rtol)
print(Q.shape, R.shape, perm.shape)   # (500, k), (k, 300), (300,)

# Randomised RRSVD
U, s, Vt = rrsvd_randomized(A, rtol)
print(U.shape, s.shape, Vt.shape)     # (500, k), (k,), (k, 300)
```

The returned rank `k` is automatically chosen so that the discarded part of the factorisation is below `rtol` relative to the norm of `A`.

## Strengths & Limitations

| Strengths | Limitations |
|-----------|--------------|
| *Speed*: Most work is done on a small projected matrix (`k ≪ min(m,n)`). | *Dense only*: Uses dense `scipy.linalg` kernels; not suited for huge sparse problems. |
| *Adaptivity*: Block size grows only as needed; no a‑priori rank guess required. | *Heuristic tolerance*: The metric `d` and the final rank test are simple heuristics; edge cases (very ill‑conditioned matrices) may need manual tweaking. |
| *Self‑contained*: No external dependencies beyond NumPy & SciPy. | *No GPU support*: Pure CPU implementation. |
| *Fallback*: Gracefully degrades to full QR/SVD when the random basis becomes full. | |

## Overall Summary

`libid.py` implements a compact toolbox for **fast, adaptive, randomised rank‑revealing factorizations**. By first approximating the column space with a cheap random basis and then performing a standard QR or SVD on the tiny projected matrix, the module delivers:

* **RRQR** (`rrqr_randomized`) → orthogonal factor `Q`, triangular factor `R`, column permutation `p`.
* **RRSVD** (`rrsvd_randomized`) → left singular vectors `U`, singular values `S`, right singular vectors `V`.

Both functions automatically infer the numerical rank from a user‑provided relative tolerance, making them handy for low‑rank approximations, dimensionality reduction, or pre‑conditioning in larger scientific‑computing pipelines.

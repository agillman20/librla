## Algorithm Descriptions

### libid (Main - Recommended)
**Randomized QR Sketching**
- Fast (typically 2-5x faster than deterministic methods)
- Adaptive rank selection via geometric block growth
- Optional power iteration for improved accuracy
- Supports both tolerance mode (rtol < 1) and rank mode (rtol >= 1)
- Stochastic (results vary slightly between runs)
- Excellent for large matrices and quick prototyping

### libid_rrqr (Deterministic Alternative)
**LAPACK geqp3 RRQR**
- Slower but deterministic (reproducible results)
- Uses standard LAPACK column-pivoted QR
- Same interface as libid
- Good for verification and when reproducibility is critical

## Recommended Usage

For most users, **libid** (randomized sketching) is recommended:
- Faster
- Adaptive rank selection
- Excellent accuracy in practice

Use **libid_rrqr** when:
- Reproducibility is critical
- Deterministic behavior required
- Verification/validation needed

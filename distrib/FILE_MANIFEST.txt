OVERVIEW
================================================================================

This distribution provides a unified randomized linear algebra library (librla)
implemented in Python, MATLAB/Octave, and Julia. The library provides efficient
sketching-based methods for low-rank matrix approximations.

================================================================================
CORE API FUNCTIONS
================================================================================

All three languages provide the same API:

1. orth_sketch(A, rtol; ...)
   - Compute orthonormal basis for column space via random sketching

2. qr_sketch(A, rtol; ...)
   - Truncated QR factorization with column pivoting

3. svd_sketch(A, rtol; ...)
   - Truncated SVD via randomized sketching

4. id_sketch(A, rtol; ...)
   - Interpolative decomposition using randomized sketching

5. id_qrpiv(A, rtol; ...)
   - Interpolative decomposition using deterministic QR pivoting

================================================================================
USAGE MODES
================================================================================

Tolerance Mode (rtol < 1):
  Adaptively determines rank to achieve specified relative accuracy
  Example: orth_sketch(A, 1e-6) -> basis accurate to 10^-6

Rank Mode (rtol >= 1):
  Returns fixed-rank approximation
  Example: svd_sketch(A, 20) -> rank-20 SVD approximation
